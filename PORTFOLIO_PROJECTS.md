# Portfolio des Projets Web et CRM

Ce document liste les principaux projets développés ou gérés dans le cadre de mes activités professionnelles et techniques.

## 1. Systèmes CRM et ERP
*   **EspoCRM (Instance Principale)** : CRM robuste basé sur PHP/Docker.
    *   *Fonctionnalités clés* : Workflow automatisé de relance, gestion des appels (Ringover/Aircall), outils de nettoyage de données personnalisés, suite de tests E2E (Playwright, PHPUnit).
*   **Filament CRM (crmfilament)** : Application Laravel 12 utilisant Filament PHP.
    *   *Fonctionnalités clés* : Architecture multi-portails (NsConseil, AlloPro), génération dynamique de documents Word, workflow de gestion de leads.
*   **EspoAOPIA** : Instance dédiée aux besoins spécifiques de l'entité AOPIA, centrée sur l'implantation de processus métier personnalisés.

## 2. Automatisation et Enrichissement de Données
*   **Projets Pappers (Collect/Locator)** : Outils d'automatisation pour l'enrichissement de données d'entreprises via l'API Pappers, utilisés pour la prospection et la qualification de leads.
*   **Leads-Allopro24** : Gestionnaire de leads optimisé pour l'activité Allopro.

## 3. IA et Développement Web
*   **AIQuizGenius** : Outil de génération de quiz assisté par IA.
*   **Vision2HTML** : Outil d'assistance au développement web utilisant la vision par ordinateur pour transformer des designs/croquis en code HTML.
*   **FreeLLM API** : Interface API permettant l'intégration de modèles de langage (LLM) dans des flux de travail métier.

## 4. Outils de Productivité
*   **Taskosaur** : Gestionnaire de tâches interne pour le suivi de la productivité.
*   **Projets ANC (Active Noise Cancelling)** : Projets techniques explorant le traitement du signal.
